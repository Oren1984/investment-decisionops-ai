## Defects found and fixed today

1. **All requests of a browser session could hang while an SSE stream was open** (seen as the unexplained J7 hang
   on 19 Oct and a J1 failure today). Root cause: the `perm()` dependency's request transaction stayed open for the
   lifetime of `/api/events`; when principal resolution updated `user_session.last_seen_at` (more than 30 s since the
   last touch), that uncommitted update held the session row lock and a pooled connection, so every other request
   of the session blocked until the stream ended. Evidence before the fix: 3 open streams → 3 connections
   `idle in transaction` on `SELECT app_user…`. Fix: `perm()` commits right after authorization
   (`backend/app/core/authz.py`). Regression test `test_permission_check_does_not_hold_the_session_row_lock` fails
   without the fix (`in_transaction() is True`) and passes with it. Live probe after the fix: 25 concurrent streams,
   no `idle in transaction` connections, `GET /api/portfolio` answered in 0.1 s.
2. **`replay-erasure-ledger` crashed in a fresh process** (`NoReferencedTableError: … 'app_user'`): the CLI did not
   register all ORM models, so restoring a backup taken before an erasure stopped at the ledger step (the app was
   correctly not started). Fix: `cli.main()` imports `app.models`. Regression: `test_deletion.py` now runs the real
   CLI in a subprocess; it fails without the fix and passes with it.
3. **Backup/restore scripts under Git Bash** passed `/c/...` paths to `docker.exe` (because of
   `MSYS_NO_PATHCONV=1`). Fix: host paths converted with `cygpath -m` when available (also in `check.sh`).
4. **`restore.ps1` did not parse** (`"$name:"` is a scope-qualified variable). Fix: `${name}`.
5. **`backup.ps1` wrote `SHA256SUMS` with a trailing CRLF**, so `sha256sum -c` could not verify the last file.
   Fix: LF-only output; cross-verified with `sha256sum -c` on a PowerShell-made backup.
6. **`check.ps1` called npm/npx through their PowerShell shims**, which rebuild arguments from the invocation line.
   Fix: `npm.cmd` / `npx.cmd` on Windows.
7. **Image vulnerabilities:** web base `caddy:2.10-alpine` → `caddy:2.11.7-alpine` (fixable HIGH/CRITICAL 98 → 4);
   `uv` no longer shipped in the app runtime image.
8. **(Afternoon) Commit after the response:** FastAPI's default `"request"` dependency scope ran `get_db`'s commit
   after the response was sent, so a client could act on a 200 before the change was visible (J6 failed in an
   afternoon full run). Fix: all 125 `Depends(get_db)` → `Depends(get_db, scope="function")`
   (`backend/app/core/db.py` docstring). Regression test `test_writes_are_committed_before_the_response_is_sent`
   fails without the fix and passes with it. Verified end to end below.

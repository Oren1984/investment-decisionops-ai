# Regulatory notes

**Not legal advice. The product makes no compliance claims.** It is a personal workspace for the owner's own
investments. The table maps topics to what the product does and where qualified review is needed.

| Topic | Relevance | Product response | Qualified review needed |
| --- | --- | --- | --- |
| Israel: Regulation of Investment Advice, Investment Marketing and Portfolio Management Law (1995); ISA guidance on algorithmic services | Personal use is the intended role. Sharing analysis with others or offering the product to others could approach regulated activity | Personal-workspace boundary; collaborators are the owner's own brokers/traders who see only what is shared; Help disclaimer | Yes, before any use beyond strictly personal |
| Israel: Privacy Protection Law, Amendment 13 (in force 14 Aug 2025) | Collaborator and meeting data | Minimisation, access control, retention purge, export, two-mode deletion, delete-all, audit | Yes (scope of obligations at this scale) |
| GDPR / UK GDPR | If EU/UK collaborators are invited, or on EU hosting | Same controls | If EU/UK collaborators are invited |
| Broker terms and market-data agreements | API use; redistribution to collaborators | Raw quotes are not part of shares by default; only synthetic data in this build | Yes, before real data is shared |
| Trading rules (pattern-day-trading, shorting, FX leverage) | Order validation | Long-only, cash-account behaviour; Live not authorized | Owner confirms account type when configuring a broker |
| Recording laws | Only if recording is ever added | Meetings are never recorded by this app | Yes, if recording is ever added |
| Tax | Out of scope | Executions available in the data export | n/a |
| AI-specific regulation | Personal use; likely outside main obligations | Transparency labels, human decision on every action | Only if offered to others |

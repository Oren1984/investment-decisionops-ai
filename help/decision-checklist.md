The app never shows a confidence percentage. Instead it shows “**7 of 10 checks passed**” with every check listed.

**Passing checks means the process was complete — not that the idea is good.**

| Check | How it is calculated |
| --- | --- |
| Scoped | At least one instrument identified |
| Two sources | At least two sources of any kind |
| Provenance | Every source has a location and an as-of time |
| Freshness | Market data newer than 72 hours |
| Portfolio context | Exposure and weights captured |
| Counterargument | At least one counterargument |
| Downside | A scenario with a negative shock was evaluated |
| Assumptions | Assumptions recorded with IDs (A1, A2…) for later review |
| No blocking findings | The critic raised no blocking issue |
| Citations (heuristic) | Library citations valid and quotes exact; see [Knowledge library](/help/knowledge-library) |

Scenarios are a linear stress view (instrument shock plus a home-currency move). There is no correlation or volatility model.
